# Funcionalidades (Features)

Esta pasta documenta as funcionalidades do sistema, planos de implementação e especificações detalhadas de cada feature desenvolvida.

# 🤖 Diretrizes para Agentes de IA

A pasta `docs/FEATURES/` centraliza a documentação de funcionalidades e especificações técnicas. Ela deve ser utilizada como referência para compreender o comportamento esperado do sistema e guiar novas implementações.

Antes de iniciar qualquer alteração, a IA deve verificar nesta pasta:

- Especificações de funcionalidades existentes.
- Planos de implementação de novas features.
- Regras de negócio associadas.

O objetivo é garantir que toda alteração esteja alinhada às especificações do projeto e que novos desenvolvimentos sejam consistentes com as funcionalidades já implementadas.

Utilize [`TEMPLATE.md`](./TEMPLATE.md) para criar a documentação de uma nova funcionalidade. O template não substitui critérios de aceite, regras de negócio ou aprovações específicas do projeto.

## Propósito como scaffold genérico

Este diretório é um template reutilizável para qualquer projeto novo. Em vez de impor features prontas, ele serve como estrutura de entrada para registrar:

- funcionalidades identificadas;
- critérios de aceite;
- regras de negócio;
- priorização e status;
- dependências entre módulos.

O agente deve usar esse espaço para documentar o produto real à medida que o projeto evolui, sem transformar o scaffold em um catálogo de funcionalidades inventadas.
