# Lições Aprendidas

Este diretório armazena o conhecimento extraído de correções validadas, refatorações e melhorias implementadas no projeto. O foco é a evolução técnica e a prevenção de erros estruturais recorrentes.

## 🤖 Diretrizes para IA
Sempre que uma tarefa de correção ou refatoração for concluída com sucesso, a IA **deve** avaliar se o aprendizado gerado tem valor preventivo. Se sim, é **obrigatório** criar um novo registro aqui.

## Padrão de Registro
Cada lição deve ser registrada em um novo arquivo Markdown (`LIC-XXX-descricao-curta.md`) seguindo o formato abaixo:

Utilize [`TEMPLATE.md`](./TEMPLATE.md) para manter consistência entre os registros.

```markdown
# [LIC-XXX] [Título da Lição/Aprendizado]

**Data:** [DD/MM/AAAA]

### 1. Problema
[Descrição clara do desafio, bug ou limitação arquitetural encontrada.]

### 2. Causa
[Análise técnica do porquê o problema aconteceu ou da limitação técnica.]

### 3. Solução
[Como o problema foi resolvido ou a melhoria implementada.]

### 4. Como evitar (Diretriz)
[Diretrizes, padrões de código ou práticas para impedir que este erro ocorra novamente ou para aplicar este aprendizado de forma proativa.]
```
